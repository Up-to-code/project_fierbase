# Firebase Project

React application source with Firebase integration.

[Source](https://github.com/Up-to-code/project_fierbase) · [Issues](https://github.com/Up-to-code/project_fierbase/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

React, Vite.

## Get started

```sh
git clone https://github.com/Up-to-code/project_fierbase.git
cd project_fierbase
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Build the project |
| `npm run lint` | Check lint rules |
